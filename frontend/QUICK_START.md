# 🚀 QUICK START GUIDE

## Get Running in 3 Minutes

### Prerequisites
- Node.js 18+ installed
- npm or pnpm package manager

### Steps

1️⃣ **Extract Files**
```bash
# If you have the archive:
tar -xzf oth-housing-export.tar.gz
```

2️⃣ **Create New React Project**
```bash
npm create vite@latest oth-housing-platform -- --template react-ts
cd oth-housing-platform
```

3️⃣ **Replace Files**
```bash
# Copy all extracted files to your project
# Or manually copy the src/ folder and config files
```

4️⃣ **Install Dependencies**
```bash
npm install
```

5️⃣ **Run Development Server**
```bash
npm run dev
```

6️⃣ **Open Browser**
```
http://localhost:5173
```

7️⃣ **Login**
```
Email: student@oth-regensburg.de
Password: anything
```
