🚀 QUICK START:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. Extract archive:
   tar -xzf oth-housing-complete-export.tar.gz

2. Create new Vite project:
   npm create vite@latest oth-housing-platform -- --template react-ts
   cd oth-housing-platform

3. Copy extracted files to project

4. Install dependencies:
   npm install

5. Run development server:
   npm run dev

6. Login with any @oth-regensburg.de email
